**Boundary of the receive-only check.** `may_reach_vehicle` treats any port string containing `://` as non-physical and does not check that a `socket://` host is loopback, so a real board behind a network serial server would pass. `active-ips` has only been run on `SITL`.

**API protections, verified in code.** Server binds 127.0.0.1 by default. A non-loopback host with a non-SIM source is refused. Control `POST` routes check Origin; a token is
checked **only if** `AEGIS_API_TOKEN` is set. `GET` routes have no authentication, and `TrustedHostMiddleware` limits hosts. The WebSocket refuses a non-local Origin. Bridge status API
is loopback by default; a non-loopback host requires a token file. Tests: `tests/unit/test_defense_safety.py`.
